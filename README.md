# e-plantShopping

## Project Overview

**e-plantShopping** (Paradise Nursery) is a front-end e-commerce web application built with React and Redux. The application allows users to browse a variety of houseplants, add them to a shopping cart, and manage their cart before checkout. 

The application features a landing page, a product listing page categorized by plant types, and a fully functional shopping cart page that dynamically updates quantities and totals.

## Features
*   **Landing Page:** A visually appealing background with company details and a "Get Started" button.
*   **Product Listing:** Displays plants grouped into multiple categories with images, names, and prices.
*   **Shopping Cart:** Shows total items, total cost, and allows users to increase, decrease, or delete items from their cart.
*   **Dynamic Navbar:** A header visible on the products and cart pages with a live cart icon counter managed via Redux.

## Technologies Used
*   React.js
*   Redux Toolkit (`@reduxjs/toolkit` & `react-redux`)
*   Vite
*   CSS3
*   GitHub Pages (for deployment)
